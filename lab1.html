Web Development Lab

Introduction to HTML

In this lab, you will learn the fundamental building blocks of the web. Focus on understanding semantic structure and proper nesting of elements.

Q1

Create a Personal Bio

Create an HTML page named bio.html. It should include:

  • A main heading with your name.
  • A paragraph describing your hobbies.
  • An unordered list of your favorite movies/books.
  • A profile image (use a placeholder if needed).
Q2

Registration Form

Design a student registration form using the <form> tag. The form must capture:

  • Full Name (Text input)
  • Email Address (Email input)
  • Date of Birth (Date picker)
  • Course Selection (Dropdown menu)
  • Gender (Radio buttons)
<!-- Expected Structure -->
<form action="/submit" method="POST">
  <label for="fullname">Name:</label>
  <input type="text" id="fullname" name="fullname" required>
  ...
</form>
